# Legal Copilot. Legal document Q&A tool that uses Anthropic API to answer legal questions.

# Paste legal document and ask questions in plain English. 

# Uses Retrieval Augmented Generation style chunking to analyze document, answer the query, and then return it.

## Stack
-- Backend: Python, FastAPI, Anthropic SDK
-- Fronted: Completely AI generated HTML/CSS/JS with zero dependencies
-- Deployed on Render.com
